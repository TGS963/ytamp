# Card schema

Use these closed node types:

- `object`: a source-backed noun or boundary.
- `process`: a real movement with input, steps, and output.
- `effect-index`: a routing index for first-order change impact.

Each object card must state its source, shape, connections, change impact, surfaces, and `See` links. Each process card must state input, movement, output, consumed objects, produced objects, and change impact.
