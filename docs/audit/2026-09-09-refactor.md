## Structure and cleanup

The reducer, runtime, official API, discovery parser, shared controls, track rows, discovery UI,
and Winamp shell now have modules for their distinct responsibilities.
Home, lyrics, skin installation, queue editing, and audio processing use named helpers.
Audio filtering, ramps, limiting, and stereo balance retain their original calculations and order.

Both RustyPipe clients use [one cache factory](../../src/rustypipe_client.rs).
The factory creates the OS cache directory before constructing the client.
On this Mac, cache and reports use `~/Library/Caches/ytamp/rustypipe`.
A missing user directory falls back to the system temporary directory, never the working directory.
A native restart and lyrics request produced the cache there and no cache at the repository root.

Removed generated output: the root cache and a 2,954,527-byte RustyPipe error report.
Removed exact duplicate evidence: two logs, totaling 500 bytes. Incoming links now use the retained copies.
The OAuth probes share token setup and retain their executable names and read-only behavior.

The source tree changed from 74 files / 926,256 bytes to 111 files / approximately 934 KB.
Smaller modules add some interface code. Most byte reduction comes from generated output, not source deletion.
Cargo machete 0.9.2 found no unused dependency with Cargo metadata enabled.
The Cargo feature graph was also reviewed. No dependency was removed.
The image wildcard became `0.25.10`, without a lockfile upgrade from the verified baseline.
