# Audit fixes — 2026-09-08

Follow-up to the [baseline audit](2026-09-08.md). All eleven reported defects have fixes in the working tree, along with the additional usability improvements below. Pre-existing unrelated research files are preserved.

## Changes

| Baseline finding | Fix |
|---|---|
| Winamp return-to-main crash | Retain the native child viewport hidden between uses, avoiding destruction of its current macOS OpenGL view. Change root visibility only on mode transitions. |
| Right-click dead zones | Handle secondary clicks across the complete row, including artist, album, and queue controls; keep stable row identities and primary-click actions. |
| Overflowing playlist submenu | Bound its size, scroll the playlist list, truncate long names, and keep New playlist accessible outside the scroll area. |
| Stale account responses | Stamp asynchronous account results with a session generation, cancel obsolete API tasks, reject stale completions, and guard API publication and credential/cache writes across account changes. |
| Out-of-order search | Match completions to the current search request identity. |
| Winamp shortcuts | Run shared keyboard handling in the active Winamp viewport. |
| Concurrent playlist creation | Correlate each completion with its own pending track by request identity. |
| Inert queue rows | Click to jump; context menu supports Play now and Remove; explicit queued tracks can be cleared. Removal preserves context and repeat order. |
| Failed library cannot retry | Retry failed loads on returning to Library and provide Refresh, with duplicate-load protection. |
| Pause during stream loading | Preserve desired pause state through decoder readiness in both reducer and playback engine. |
| Minimum-width layout | Reserve row controls, truncate long text, and arrange the player bar in two rows. Keep song titles explicitly left-aligned. |

Additional changes: Japanese fallback fonts in the main UI and Winamp rasterizer, real playlist titles/counts, playlist search parsing and rendering, control tooltips, explicit unavailable EQ/balance tooltips, updated README and runtime documentation, removal of temporary input traces, and strict Clippy cleanup. The bundled font license and attribution are included.
