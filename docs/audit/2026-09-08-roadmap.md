# Queue, playback, transitions, lyrics, and menu bar

Implemented in the user-authorized order recorded in [the work queue](../implementation-queue.md).

## Queue editing

Both interfaces share selection, Shift ranges, Cmd/Ctrl toggling, Select All, Delete/Backspace, Enter, drag/drop insertion, and the same context actions. Song titles remain left-aligned. Editing applies to upcoming occurrences, preserving duplicate songs and the distinction between explicit queue entries and context tracks. Manual order persists across restart and Previous. An invalid jump now does nothing instead of clearing explicit entries and stopping playback.

Native evidence: [drag/context menu](evidence/queue-main-drag-menu.png), [range selection](evidence/queue-main-range.png), [Delete](evidence/queue-main-delete.png), [Winamp drag/context menu](evidence/queue-winamp-drag-menu.png). These initial screenshots predate the final change that removes inactive button backgrounds in the normal queue.

The production skin probe now also drags and deletes playlist entries. All six historical skins pass at 1×, 2×, and 4×: [results](evidence/roadmap-skins.txt).

## Playback and transitions

- Player reports carry the playback generation through to the reducer. A late start, position, end, or failure cannot affect a newer track or revive signed-out playback.
- Seeks made while loading retain the latest requested position and apply when the decoder is ready, preserving Pause.
- A failed active download reports an interruption instead of masquerading as a normal track ending.
- The next expected decoder prepares in advance, with cancellation when the queue changes. Hover prefetching does not replace the prepared-next target. In-flight prefetch IDs prevent duplicate downloads.
- End detection runs every 10 ms and cannot be starved by commands. Position notifications stay at 250 ms.
- Incoming events and native menu commands run in eframe's background logic callback, so hidden/minimized windows no longer stall queue progression or menu actions.

Tests include 1,000 rapid skip cycles with stale reports, 100 loading seeks, failed-buffer reporting, decoder cancellation, queue/source/repeat invariants, and actual decoded PCM entering an offline mixer. One local prepared-handoff measurement was **156 µs**: [measurement](evidence/transition-measure.txt). This excludes the UI round trip, device buffering, network stalls, and end-detection interval; it is not an audible-gap measurement or a claim of sample-accurate gapless playback.

Native playback advanced from A Sky Full of Stars to Yellow through the prepared decoder: [log](evidence/transitions-native.txt), [next-track screenshot](evidence/transitions-next.png).

## Lyrics

A resizable native lyrics window is accessible from the main player, Winamp title-bar menu, and macOS menu bar. It follows the current track, shows provider attribution, distinguishes unavailable lyrics from request failures, and offers Retry. Requests have a 20-second timeout, are canceled when superseded or closed, and ignore stale results. Lyrics are neither bundled nor persisted; this is plain lyrics display, not synchronized highlighting.

The live Yellow probe returned lyrics and attribution without printing the lyric text: [availability result](evidence/lyrics-availability.txt). The native window was opened from Winamp, closed, and reopened from the main interface. Tests cover track changes, stale replies, unavailable lyrics, retries, closing, and sign-out/reopen request identities.

## macOS menu bar

The native ♫ menu shows the current track and provides Play/Pause, Previous, Next, Lyrics, Hide/Show, and Quit. Cocoa objects and target lifetimes are confined to the main thread. Existing media-key integrations remain available on other platforms; Windows/Linux tray menus have not been implemented in this pass.

The [repeatable native smoke test](../../scripts/smoke-menubar.swift) passes in [normal mode](evidence/menubar-main.txt) and [Winamp mode](evidence/menubar-winamp.txt), including track advancement and Pause with all windows hidden, restoration, lyrics, and a clean quit. It exercises the current queue and can briefly play audio; it does not write account data.
