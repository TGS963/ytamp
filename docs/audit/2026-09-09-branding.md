# Desktop branding and platform checks

Source commit: `82f4b5a`.

The app uses the plain Aero artwork from the supplied PSD export. The later PNG with an equalizer badge is not used. The source PNG is unchanged after export. ICO and ICNS files contain resized copies. The macOS menu bar uses a monochrome vector trace of the bolt as a template image.

The sidebar uses the text's natural width and a two-point upward offset. Native macOS checks confirm the sidebar, Dock, menu image, and packaged app icon. Hide/Show and Lyrics pass through the image menu. Three Winamp/EQ/playlist/shade/return cycles pass.

Windows resources embed the icon in the executable. Linux packages include the desktop entry and hicolor icon with app ID `io.github.TGS963.ytamp`. All child viewports share that identity and icon. Native Windows/Linux tray menus remain planned.

The package script passes checks for all three layouts and repeat staging. Local all-target tests and strict Clippy pass.

Platform CI: [Windows and Linux pass](https://github.com/TGS963/ytamp/actions/runs/34320995461). Windows passes 394 library tests; Linux passes 393. Both also pass all-target checks, Clippy, package staging, and native startup.

Linux startup uses Xvfb and Mesa. Windows startup uses pinned Mesa because the runner's stock OpenGL 1.1 cannot start egui. Each startup check requires a visible window for 15 seconds. These checks do not test hardware audio or Wayland.

Older imported skins retain their original lettering because it is part of `titlebar.bmp` and `eqmain.bmp`. The titlebar renderer draws those sprites directly. The built-in skin generator writes YTAMP.
